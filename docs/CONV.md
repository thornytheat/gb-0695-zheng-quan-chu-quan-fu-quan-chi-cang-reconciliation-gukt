# 可转债转股复核与发布

进入转股期后的可转债，持有人在分红调整转股价前后分批申报转股。本模块按处理日裁决
适用转股价，精确拆分应转股票、不足一股折现现金与继续保留的整张债券，整批对账相符且
复核通过后才允许发布，同一笔申报重试不会重复转股。

入口：http://localhost:18209/conv/ （页面 `/conv/work/1`～`/conv/work/5`）。

## 五个阶段

| 阶段 | 名称 | 职责 |
|---|---|---|
| C1 | 数据接收 | 解析债券、价格事件、申报三类输入，校验整张面值与持仓上限 |
| C2 | 转股价裁决 | 按处理日选取生效转股价；标注公告前受理、确认状态、新/原价执行 |
| C3 | 转股拆分 | 整数股向下取整、零头折现金、未申请整张保留；按指纹幂等去重 |
| C4 | 整批对账 | 逐笔守恒、整张保留、超发、债券维度持仓守恒、现金复算 |
| C5 | 复核发布 | 仅“对账相符 + 复核通过”可发布；发布幂等，重复转股被拒绝 |

## 关键规则与陷阱处理

1. **公告前受理、公告后处理（最麻烦的情形）**
   转股价随分红等公司行动调整，价格事件自生效日起适用。处理日统一按当日生效的
   **新价** 执行；若申报受理日早于价格事件生效日且当时尚未确认，显式标注
   “公告前受理／未确认／新价执行”，既不会在公告后仍按旧价，也保留证据说明裁决依据。

2. **不足一股折现金，整张债券不注销**
   - 转换比率 = 申请转股面值 ÷ 转股价（Decimal 高精度，精度 50 位，全程无浮点）；
   - 应转股票向下取整；整数股对应面值之外的零头面值，按
     `零头面值 × 转股价 ÷ 100` 四舍五入到分折现；
   - 申报守恒：`申请面值 = 转股面值 + 零头面值`；
   - 未申请转股的整张债券继续保留：`保留面值 = 持仓面值 − 申请面值`，恒为 100 的
     整数倍，绝不注销整张；债券维度 `持仓 = 转股 + 零头 + 保留 + 跳过申请`。

3. **同一笔申报重试不重复转股**
   指纹 = `债券|申报号|申请面值|适用转股价` 的 SHA256。发布时把执行笔写入
   `processed` 表；之后任何批次重算，命中指纹的申报一律“重复跳过”，应转股票与
   折现现金均为 0。转股价再次调整后指纹变化，同一申报号可作为新指令再次转股。
   发布前二次查指纹，全部为跳过笔的批次直接拒绝（409 DUPLICATE）。

4. **整批对账相符才允许发布**
   C4 任一对账项为“差异”即 `balanced=false`，发布接口返回 409 BALANCE；
   复核未通过返回 409 REVIEW。同批次重复发布幂等返回 `reused=true`。

## 输入

- 结构化 JSON：`{"processing_date","bonds":[],"price_events":[],"instructions":[]}`；
- 组合 CSV：首列 `section`（`meta`/`bond`/`price_event`/`instruction`），
  `meta` 行的处理日写在 `event_id` 列。表头见 `sample_data/conv/conversion.csv`。
- 面值字段必须为 100 的非负整数倍（整张），`face_amount ≤ holding_face`，否则 422。

## 接口（前缀 `/conv`）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/conv/api/run` | JSON 或 file 字段上传 CSV；空对象运行样例 |
| POST/GET | `/conv/api/c1`…`/conv/api/c5` | 独立运行到指定阶段 |
| GET | `/conv/api/runs/<id>` | 批次详情 |
| GET | `/conv/api/history` | 历史批次 |
| POST | `/conv/api/review` | `run_id,revision,decision`（通过/退回），乐观锁版本 |
| POST | `/conv/api/publish` | 对账相符且复核通过后发布，幂等 |
| GET | `/conv/api/evidence.csv?run_id=` | 含五阶段、转股明细、债券维度对账的证据导出 |

错误：结构/数值问题 422，版本冲突或发布条件不满足 409，批次不存在 404，
非对象 JSON 400。数据存于 `CONV_DB`（默认 `data/conv.sqlite3`，容器内 `/data`）。
